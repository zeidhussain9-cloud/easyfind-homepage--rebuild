# EasyFind Property Solutions — Visual & Creative Rules

**Status:** Approved for Task 06 on 30 September 2026  
**Applies to:** the website baseline and future EasyFind creative work  
**Owner:** EasyFind Property Solutions

## 1. Creative direction

EasyFind should feel **local, capable, clear, and properly handled**. Visual
work should make the next practical step obvious without looking like a
property listing portal, investment product, or generic lead-generation page.

Use:

- clear, human explanations rather than hype;
- real local context and useful decision routes;
- proof-led layouts only when the proof is authentic and current;
- calm hierarchy, generous spacing, and strong mobile legibility;
- one clear action per section, normally an enquiry or WhatsApp route.

Avoid:

- live listings, inventory grids, availability feeds, or directory-style
  locality pages;
- unsupported claims about ratings, property counts, guarantees, credentials,
  investment returns, or market performance;
- stock imagery presented as EasyFind's own work;
- decorative complexity that hides the enquiry path.

## 2. Current visual baseline

The live homepage is the source of truth for the current implementation. Keep
the following values stable unless a new, explicit brand decision supersedes
them:

| Role | Current value |
| --- | --- |
| Deep navy | `#14304d` |
| Brand navy | `#1A3A5C` |
| Homepage navy | `#17324f` |
| Gold accent | `#C9A84C` |
| Homepage gold | `#b89445` |
| Soft gold | `#d9bd6b` |
| Warm cream surface | `#f7f5ef` |
| Neutral surface | `#F8F9FB` |
| Main ink | `#223044` |
| Muted text | `#667384` / `#6B7280` |
| Border | `#E5E7EB` |

Use navy for trust, structure, and dark sections; gold sparingly for emphasis,
active states, numbers, and primary calls to action; cream and neutral
surfaces for breathing room. Text and controls must retain accessible contrast.

The approved logo assets are the existing `public/easyfind-logo.jpg` and
`public/easyfind-logo.webp`. Do not replace them with a look-alike mark.

## 3. Type and layout

- Use the existing site type system; serif display treatment is reserved for
  major headings and editorial emphasis, with a clean sans-serif for body copy,
  labels, controls, and navigation.
- Headings should be short, specific, and sentence case where possible.
- Use generous vertical spacing and readable line lengths.
- Prefer rounded controls and restrained borders over heavy card decoration.
- Keep desktop layouts balanced and two-column where the content calls for it;
  stack cleanly on mobile with no horizontal overflow.
- Keep focus states, labels, error states, and success states visible and
  understandable.

## 4. Photography and proof

- Use original EasyFind/on-ground photography only when permission is confirmed.
- Do not publish identifiable people, properties, reviews, or case studies
  without the appropriate permission.
- Google Business Profile reviews may be shown only while authentic and current.
- Never imply that a stock or illustrative image is a completed EasyFind job.

## 5. Template and content rules

Reusable website or social templates must:

1. identify EasyFind Property Solutions accurately;
2. use the palette and logo baseline above;
3. remain legible at mobile size;
4. show one clear next step;
5. distinguish confirmed facts from illustrative guidance; and
6. avoid publishing unverified inventory or stale availability.

This document defines the visual guardrails. It does not authorize social
publishing, paid campaigns, or website changes that require a separate
approval.
