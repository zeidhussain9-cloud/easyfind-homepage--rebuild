# EasyFind website operating rules

- The repository contains only the public EasyFind Property Solutions website.
- Keep the homepage enquiry-led; do not add live listings or inventory feeds.
- Preserve the approved navy, cream, and gold visual language.
- Keep lead delivery inside the existing verified form pipeline.
- Never commit secrets or modify deployment credentials.
- Work on branches and verify `npm run build` before publishing.
- Production deploys from `main` to Render service `srv-d98o56btqb8s739ek100`.
